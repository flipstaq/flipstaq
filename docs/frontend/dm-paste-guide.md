# How to Paste Images in DM - User Guide

## 📸 Paste Images Directly into Chat

Just like Discord, WhatsApp, and Telegram, you can now paste images directly into your DM conversations!

### ✨ How It Works

1. **Copy any image**:

   - Take a screenshot (Windows: Win+Shift+S, Mac: ⌘+Shift+4)
   - Right-click and copy an image from a webpage
   - Copy an image file from your computer

2. **Paste into chat**:

   - Click in the message input box
   - Press **Ctrl+V** (Windows) or **⌘+V** (Mac)
   - The image will automatically appear in the preview area

3. **Send your message**:
   - Add text if you want
   - Click Send to share the image

### 🎯 What You'll See

- ✅ **Green success message**: "Image pasted successfully! Ready to send."
- 🖼️ **Image preview**: Your image appears above the input box
- 💬 **Smart placeholder**: Shows paste hint when no files are attached

### 📋 Supported Formats

- **Image Types**: JPEG, PNG, WebP, GIF
- **Size Limit**: Up to 10MB per image
- **File Limit**: Maximum 10 files per message

### 🚫 What Happens If...

- **File too large**: Red error message appears
- **Wrong file type**: Only images are accepted from paste
- **Too many files**: Cannot exceed 10 files per message
- **Paste text**: Regular text paste works normally

### 💡 Pro Tips

- You can still use the attachment button (📎) for manual file selection
- Mix pasted images with typed messages
- Works great with the reply feature - paste images in your replies!
- All pasted images get automatically organized names

### 🌐 Works Everywhere

- ✅ All modern browsers (Chrome, Firefox, Safari, Edge)
- ✅ Windows, Mac, and Linux
- ✅ Desktop and tablet devices
- ✅ Both English and Arabic interfaces
